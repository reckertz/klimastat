6. template + slot

Ein template definiert die Struktur einer Web Component. Zwei slot-Platzhalter nehmen unterschiedliche Inhalte auf. Die folgende Liste wird dynamisch aus Daten erzeugt.

template ist zunächst unsichtbar. Erst die JavaScript-Klasse klont es in einen Shadow DOM. Die slot-Elemente setzen die Inhalte an den vorgesehenen Stellen ein.
